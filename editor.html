Como publicar suas mudanças
  1. Ajuste tudo aqui — a prévia ao lado atualiza na hora (suas mudanças ficam salvas neste navegador).
  2. Clique em Baixar config.js.
  3. No GitHub, abra o repositório → Add file → Upload files → envie o config.js baixado → Commit changes. Em 1–2 minutos o site atualiza.
